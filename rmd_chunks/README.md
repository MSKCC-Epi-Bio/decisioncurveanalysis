# R Markdown Chunks Directory (`rmd_chunks`)

This directory contains the source code snippets used in the `dca-tutorial.Rmd` file and the scripts generated from those snippets.

## Files Directly in `rmd_chunks`

The files `r-chunks.R`, `stata-chunks.do`, `sas-chunks.sas`, and `python-chunks.py` contain the raw code chunks for each respective language. These files serve two primary purposes:

1.  **Code Display:** They are read by `knitr::read_chunk` within `dca-tutorial.Rmd`. This allows the R Markdown file to reference and display these code chunks in the appropriate tabbed sections of the rendered tutorial.
2.  **Script Generation Input:** They are used as input by the `.convert_chunks_to_script` R function defined in the setup chunk of `dca-tutorial.Rmd`. This function processes these chunk files to create complete, runnable scripts.

**These files are essential and should not be deleted.**

## `chunks_as_scripts` Subdirectory

This subdirectory contains the complete, runnable scripts generated by the `.convert_chunks_to_script` function when `dca-tutorial.Rmd` is processed (knit).

*   `dca-script.R`
*   `dca-script.do`
*   `dca-script.sas`
*   `dca-script.py`

These generated scripts are the target files for the "Download DCA Code" links provided in the rendered `dca-tutorial.html` output files. They allow users to easily download the full code for a specific language presented in the tutorial.

**While generated, these files serve a specific purpose as downloadable artifacts and should not be deleted unless the generation process or the download links in `dca-tutorial.Rmd` are modified.**
